## QC checklist for the library

Go through the full exercise list and check each row.

**Label matches footage.** Open each uploaded video and confirm it is the movement the
label says. Pay closest attention to exercises with more than one variation, since
that is where every error found so far has been.

**Variations are complete.** For any exercise with a standard version plus variations
(tempo, single arm, single leg, with a press), confirm every version named in the
program actually exists as its own video. Known gaps so far:

- Leg curl: standard version missing, tempo and single leg present
- Hanging squat clean: only the clean and press version found
- Dumbbell shoulder press: only the single arm version found

**Anything missing gets flagged, not guessed.** If a movement was never filmed, do not
substitute a similar clip on your own. Send Hannah the list and she will decide which
ones get a generic replacement and which get reshot.

**Audio.** Any clip filmed with gym music playing needs a cleanup pass so the captions
transcribe the coaching audio rather than the song. Barbell deadlift is a confirmed
one. Check the rest of the clips from the same session.

**Tags.** Confirm the incorrect "H Goldie" handle is gone from every clip. Her handle
is @hannahgoldy, spelled with a Y.
